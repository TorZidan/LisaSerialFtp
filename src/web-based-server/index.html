Lisa Serial FTP Server

The Lisa Serial FTP server, running in your browser: no install needed. How to use it, and what it can do: README.

This browser cannot open serial ports. Use Chrome or Microsoft Edge on a computer, and open this page over https (or from http://localhost).

1. Files to serve

The default is this project on GitHub: on the Lisa, get src/client/LisaSerialFtpClient.text. The site must allow browser downloads (CORS); raw.githubusercontent.com does. Web sites cannot list a folder, so list uses the GitHub API for a raw.githubusercontent.com address (60 listings an hour), and an index.json file in the folder for any other address.

2. Serial port

8 data bits, no parity, 1 stop bit, no flow control, as the Lisa client uses. Start at the rate the Lisa client is at; its baud command then changes both, and quit comes back to this one.

stopped

The browser lists only real serial ports, such as a USB serial adapter. It cannot see pseudo-terminals (PTYs), so this page cannot talk to the LisaEm emulator: use LisaSerialFtpServer.py for that.
